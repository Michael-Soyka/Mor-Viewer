# Mor Viewer

Просмотрщик ресурсов игры «Мор. Утопия» (Pathologic): открывает VFS-архивы и распакованные файлы, показывает текстуры, шрифты, модели, сцены уровней, карты, тексты и звук.

## Возможности

| Тип | Расширения | Что умеет |
|---|---|---|
| Текстуры | `.tex`, PNG, JPEG, TGA | просмотр по каналам и масштабу, экспорт в PNG |
| Шрифты | `.ft` | атлас глифов и пример текста |
| Модели | `.mesh`, `.mms`, `.mma`, `.lsh` | 3D-просмотр, анимации персонажей, экспорт в glTF |
| Сцены | `.isc`, `.osc` | интерьеры и уровни целиком: карты освещения, источники света, вода с отражениями, небо и время суток, навигационные пути |
| Карты | `.map` | карта с подписями |
| Тексты | `.xml`, `.txt`, `.json` | подсветка синтаксиса |
| Звук | `.ogg` | воспроизведение |
| Прочее | любые | hex-просмотр, экспорт как есть |

Интерфейс на русском и английском.

## Минимальные требования

| | |
|---|---|
| ОС | Windows 10 и новее (64 бит), Linux, macOS 11 и новее |
| Графический API | Vulkan (Windows, Linux) или Metal (macOS); OpenGL и DirectX 12 не поддерживаются |
| Видеокарта | с драйвером Vulkan и текстурами до 8192 пикселей: NVIDIA GeForce GTX 600, AMD Radeon HD 7000, Intel HD Graphics 500 и новее; на macOS — любой Mac с Metal |
| Данные | файлы игры «Мор. Утопия» (2005): папка установки или её VFS-архивы |

Без драйвера Vulkan программа не запустится. Отсечение невидимой геометрии в 3D использует `multi_draw_indirect_count`; без него сцены рисуются медленнее, а строка состояния просмотрщика покажет, чего не хватает.

## Сборка

Нужен Rust с поддержкой edition 2024 (1.85+).

Парсеры форматов лежат в отдельном репозитории `mor-parsers` и подключаются по относительному пути, поэтому его нужно положить рядом:

```
mor-parsers/
mor-viewer/
```

```sh
cargo run --release
```

Отладочная сборка тоже годится: зависимости в ней собираются с оптимизацией, иначе декодирование текстур слишком медленное.

## Запуск

```sh
mor-viewer [папка_с_данными | архив.vfs | файл_игры]
```

Без аргумента берётся путь из переменной окружения `PATHOLOGIC_DATA`.

Отдельные файлы игры (`.mesh`, `.tex`, `.ft`, `.isc` и остальные) открываются напрямую, без архива: через «Файл → Открыть файлы…», аргументом командной строки или перетаскиванием в окно. Каждый открывается в своей вкладке, в дереве они не появляются. Модель ищет свои текстуры среди открытых файлов и в архивах: если текстура открыта вместе с моделью, она наложится, иначе модель будет без неё.

По умолчанию из папки `data` открываются только архивы `.vfs`. Распакованные файлы — опция «Загружать распакованные папки» в настройках, на странице «Игра»:

- **папка `data`** — вместе с архивами открываются все папки рядом с ними, например и `Actors.vfs`, и распакованная `Actors/`. Когда модель или сцена ссылается на файл по имени, он сначала ищется в распакованных папках, потом в архивах, так что правленые файлы подхватываются сразу;
- **папка без архивов** — открывается целиком как распакованная: `.mesh`, `.tex`, `.ft` и остальное лежат в ней как есть.

Независимо от опции распакованную папку можно добавить через «Файл → Открыть распакованную папку…».

## Управление в 3D

- **Модель:** левая кнопка — вращение, правая или средняя — сдвиг, колесо — приближение.
- **Уровень:** перетаскивание — обзор, `W` `A` `S` `D` — движение, `Q` / `E` — вниз и вверх, `Shift` — быстрее, колесо — скорость.
- Двойной щелчок возвращает камеру на исходную позицию, щелчок по маркеру света выключает или включает его.

## Структура

```
src/
  main.rs, app.rs   запуск и главное окно
  settings.rs       настройки
  i18n.rs           локализация (тексты в locales/)
  data/             архивы, определение типа файлов, декодирование, экспорт
  render/           GPU: модели, отсечение, вода, небо, анимация, загрузка сцен
    shaders/        WGSL-шейдеры
  ui/               тема, виджеты, иконки, заголовок окна
  viewer/           просмотрщики по типам файлов
    model/          3D-просмотрщик: камера, меню, оверлеи
```

Правила оформления кода — в [CLAUDE.md](CLAUDE.md).
