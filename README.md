# Mor Viewer

Просмотрщик ресурсов игры «Мор. Утопия» (Pathologic): открывает VFS-архивы и папки с данными, показывает текстуры, шрифты, модели, сцены уровней, карты, тексты и звук.

## Возможности

| Тип | Расширения | Что умеет |
|---|---|---|
| Текстуры | `.tex`, PNG, JPEG, TGA | просмотр по каналам и масштабу, экспорт в PNG |
| Шрифты | `.ft` | атлас глифов и пример текста |
| Модели | `.mesh`, `.mms`, `.mma`, `.lsh` | 3D-просмотр, анимации персонажей, экспорт в glTF |
| Сцены | `.isc`, `.osc` | интерьеры и уровни целиком: карты освещения, источники света, вода с отражениями, небо и время суток, навигационные пути |
| Карты | `.map` | карта с подписями |
| Тексты | `.xml`, `.txt`, `.json` | подсветка синтаксиса |
| Звук | `.ogg` | воспроизведение |
| Прочее | любые | hex-просмотр, экспорт как есть |

Интерфейс на русском и английском.

## Сборка

Нужен Rust с поддержкой edition 2024 (1.85+).

Парсеры форматов лежат в отдельном репозитории `mor-parsers` и подключаются по относительному пути, поэтому его нужно положить рядом:

```
mor-parsers/
mor-viewer/
```

```sh
cargo run --release
```

Отладочная сборка тоже годится: зависимости в ней собираются с оптимизацией, иначе декодирование текстур слишком медленное.

## Запуск

```sh
mor-viewer [папка_с_данными | архив.vfs]
```

Без аргумента берётся путь из переменной окружения `PATHOLOGIC_DATA`. Архивы можно открыть и из интерфейса.

## Графика

Рисование только через Vulkan (Windows, Linux) и Metal (macOS); OpenGL и DirectX 12 не поддерживаются. 3D-просмотр рассчитан на вычислительные шейдеры и непрямую отрисовку с `multi_draw_indirect_count`; чего из этого нет у видеокарты, просмотрщик перечислит в строке состояния.

## Управление в 3D

- **Модель:** левая кнопка — вращение, правая или средняя — сдвиг, колесо — приближение.
- **Уровень:** перетаскивание — обзор, `W` `A` `S` `D` — движение, `Q` / `E` — вниз и вверх, `Shift` — быстрее, колесо — скорость.
- Двойной щелчок возвращает камеру на исходную позицию, щелчок по маркеру света выключает или включает его.

## Структура

```
src/
  main.rs, app.rs   запуск и главное окно
  settings.rs       настройки
  i18n.rs           локализация (тексты в locales/)
  data/             архивы, определение типа файлов, декодирование, экспорт
  render/           GPU: модели, отсечение, вода, небо, анимация, загрузка сцен
    shaders/        WGSL-шейдеры
  ui/               тема, виджеты, иконки, заголовок окна
  viewer/           просмотрщики по типам файлов
    model/          3D-просмотрщик: камера, меню, оверлеи
```

Правила оформления кода — в [CLAUDE.md](CLAUDE.md).
